IPTV-Auto-Next

自动采集、筛选和验证 IPTV 直播源，持续生成可用的 IPv4 直播订阅。

项目目标

尽可能筛选出真正可用的直播线路，自动生成并更新 IPTV 订阅文件。

自动更新

- 每天北京时间 06:17 自动运行。
- 支持 GitHub Actions 手动运行。
- 支持手动测试运行。

订阅文件

自动生成的订阅文件计划发布在：

- "output/iptv.m3u"
- "output/iptv.txt"

项目进度

项目开发中，具体开发阶段、完成情况和测试结果以 "PROGRESS.md" (PROGRESS.md) 为准。

项目总流程和开发要求以 "MASTER_PLAN.md" (MASTER_PLAN.md) 为准。
