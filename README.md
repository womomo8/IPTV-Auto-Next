# IPTV-Auto-Next

一个基于 Python 开发的自动化 IPv4 IPTV 直播源收集与发布系统。

## 项目简介

本项目致力于自动收集公开来源的 IPTV 直播源，执行严格的网络安全校验和底层媒体结构探测，每个频道筛选并保留最多 3 条可用线路，最终自动生成标准的 M3U 和 TXT 订阅文件。

系统部署在 GitHub Runner 上，每天定时更新并自动发布。

## 核心声明与边界

1. **国内播放不承诺**：程序探测通过仅代表符合基础技术结构，**不代表中国大陆真实网络能够访问，也不代表播放器能正常播放**。所有订阅默认标记为 `unverified`（未验证），如需验证需真实国内网络环境实测。
2. **格式边界**：首版仅支持未加密的 MPEG-TS 媒体流，拒绝复杂的 HLS 加密和高级特性。
3. **安全合规**：仅处理公开或授权的来源，全面防范 SSRF 等网络攻击，不绕过任何 DRM、付费墙。
